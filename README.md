# Personal Notes Manager 📝

## About the Project
Personal Notes Manager is a simple Python project that allows users to save and view personal notes using a text file. It is designed for beginners to practice Python file handling and loops.

## Features
- Add new notes
- View all saved notes
- Store notes permanently in `notes.txt`
- Handle missing notes files
- Simple menu-driven interface

## Technologies Used
- Python
- File Handling
- While Loop
- If-Else Statements
- Exception Handling

## How It Works
1. Select **Add Note** to enter and save a note.
2. Select **View Notes** to display your saved notes.
3. Select **Exit** to close the program.

## Example
```text
===== Personal Notes Manager =====

1. Add Note
2. View Notes
3. Exit

Enter choice: 1
Enter your note: Submit assignment on 22 October 2026.
Note saved successfully!
```

## Learning Outcomes
- Learned how to create and write to text files.
- Practiced reading stored information.
- Understood loops and conditional statements.
- Learned basic exception handling.
